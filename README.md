# Chiselturn site

Landing, privacy and support pages for Chiselturn, an iPhone puzzle game
(repo `nguyenvanlamm/chiselturn`). Served by GitHub Pages from `main`:
https://nguyenvanlamm.github.io/chiselturn-site/

- `index.html` — landing page
- `privacy.html` — privacy policy (App Store "Privacy Policy URL")
- `support.html` — support page (App Store "Support URL")
- `assets/` — icon and screenshots from the game

Every push to `main` republishes the site. No build step and no workflow.
